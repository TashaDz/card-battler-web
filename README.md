# Card Battler — playable web build

Прототип PvP-стратегии с розыгрышем карт: карту тянешь из руки вверх, и
заклинание срабатывает. Играется в браузере (телефон в портрете или десктоп):
https://tashadz.github.io/card-battler-web/

Только билд; исходники — в приватном репозитории TashaDz/card-battler.
